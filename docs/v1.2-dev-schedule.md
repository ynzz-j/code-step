| 2.3 | `envStore.ts` 新增 | `src/stores/envStore.ts`（新增） | 0.5d | P0 |

### 具体工作内容

**2.1 env_checker.rs**
- 支持 4 种语言检测：java（javac）/ python（python3）/ javascript（node）/ cpp（g++）
- `check_env(language)` 命令：先查缓存 → 检测 → 写缓存
- `check_all_envs()` 命令：批量检测
- 注意：Windows / macOS / Linux 各有差异，需分平台处理

**2.2 缓存逻辑**
- TTL = 1 小时，`checked_at + 3600s < now` 时过期
- 用户手动"刷新检测"可强制清除缓存

**2.3–2.4 前端 Store + Hook**
- `envStore`：`envStatus` map + `checkEnv()` + `clearCache()`
- `useEnvCheck(language)`：返回 `{ envReady, effectiveMode, checkEnv }`
- `effectiveMode`：coding 步骤在无环境时自动降级为 typing

**2.5 EnvCheckModal**
- 触发时机：`startCourse()` 时，课程含 coding 步骤且环境不可用
- 内容：语言名称 + 版本要求 + 安装链接 + 两个按钮（"先跳过" / "去安装"）
- "先跳过"：`onSkipToTyping()` → 降级模式进入
- "去安装"：`shell.open(installUrl)` 打开浏览器

**2.7 LearnPage 降级**
- 步骤渲染时判断 `effectiveMode`
- 降级时显示提示 Badge："Typing 模式（未检测到 Java 环境）"

### 验收标准
- [ ] Java/Python/Node 三种环境检测正常工作（macOS + Windows 均验证）
- [ ] 1 小时内重进课程命中缓存，控制台可见"cache hit"日志
- [ ] 无环境时 Modal 正确弹出，两个按钮行为正确
- [ ] 降级模式下 coding 步骤可正常打字完成并记录进度
- [ ] Badge 提示文字清晰

### 具体工作内容

**3.1 user_center.rs**
- `get_learning_summary()`：聚合总时长 / 完成课程数 / 步骤数 / 连续天数
- `get_course_progress_detail(course_id)`：单课详情
- `get_learning_calendar(year, month)`：热力图数据（从 `learning_daily_summary` 查）
- 连续天数算法：从今天往前遍历 `learning_daily_summary`，连续有记录的天数

**3.2 daily_summary upsert**
```sql
INSERT INTO learning_daily_summary (user_id, date, minutes_learned, steps_completed)
VALUES (?, date('now'), ?, 1)
ON CONFLICT(user_id, date) DO UPDATE SET
  minutes_learned = minutes_learned + excluded.minutes_learned,
  steps_completed = steps_completed + 1
```

**3.4–3.5 页面**
- 统计卡片：总时长 / 完成课程 / 完成步骤 / 连续学习天数（4 格）
- 课程进度列表：进度条 + 百分比 + 上次学习时间

**3.6 热力图**
- 近 90 天，每日一格，颜色 4 级（0 / 1-2步 / 3-5步 / 6+步）
- 用 CSS Grid 实现，不引入 D3 等库（保持轻量）
- hover 时 tooltip 显示当日步骤数

## 风险与缓解

| 风险 | 可能性 | 影响 | 缓解方案 |
|-----|--------|------|---------|
| Windows 环境变量检测与 macOS 差异大 | 高 | 中 | env_checker.rs 中 `#[cfg(target_os)]` 分平台处理，提前在两个平台各验证一次 |
| 热力图 CSS Grid 在小屏幕截断 | 中 | 低 | 限制显示 60 天，或加横向滚动 |
| 8 门课程 JSON 逐一补字段繁琐 | 低 | 低 | 写一个 Python 脚本批量补全 category/tags |
| 连续天数计算跨年边界 | 低 | 低 | 用 chrono 做日期计算，避免手动字符串处理 |
| 迁移脚本对已有用户数据破坏 | 低 | 高 | 所有 ALTER TABLE 仅 ADD COLUMN，不删除，向后兼容 |
