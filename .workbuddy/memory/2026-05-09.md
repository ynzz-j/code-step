## codestep-course-dev Skill 更新（统一结构版）

### 更新背景
按照用户提供的统一结构要求重新更新 skill：
- 目录结构改为：`courses/{mode}/{language}/{courseId}/`
- 每门课程有独立的 `course.json`（Manifest 格式），不再有内嵌 `courses[]`
- `course.json` 必填字段：`id`, `mode`, `language`, `title`, `description`, `category`, `difficulty`, `concepts`, `estimatedMinutes`, `steps`
- `steps` 字段是相对路径数组，相对于 `course.json` 所在目录解析
- 后端通过扫描目录发现课程列表，不再依赖内嵌 `courses[]`

### 更新文件
1. `SKILL.md`：全面重写，反映新的统一目录结构和单课程 Manifest 格式
2. `references/course-template.json`：从"语言包格式（含 courses 数组）"改为"单课程 Manifest 格式"

### 关键变化对比

| 项目 | 旧结构 | 新结构 |
|------|--------|--------|
| course.json 位置 | `courses/{mode}/{language}/course.json` | `courses/{mode}/{language}/{courseId}/course.json` |
| course.json 内容 | 含 `courses[]` 数组（多课程） | 单课程 Manifest（无 courses 数组） |
| 步骤位置 | `steps/{courseId}/steps/step-XX.json` | `steps/step-XX.json`（直接在课程目录下） |
| 课程发现 | 读取 course.json 中的 `courses[]` | 后端扫描目录 |

### 目录结构示例（新）

```
courses/typing/javascript/js-hello/
├── course.json       # 单课程 Manifest
└── steps/
    ├── step-01.json
    ├── step-02.json
    └── ...
```
